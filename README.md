# Mente Activa

Sesión de estimulación cognitiva de 30/40/50 minutos para adultos mayores, pensada para tablet.

8 actividades: orientación y charla, memoria de parejas, atención, cálculo, refranes, ordenar pasos, categorías, relajación y cierre. Tres niveles, instrucciones con voz, sin castigos por error.

Se instala como app ("Añadir a pantalla de inicio") y funciona sin internet. El historial de sesiones se guarda **solo en el dispositivo**; no se envía ningún dato.
